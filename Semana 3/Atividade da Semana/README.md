# Rick and Morty

## API utilizada
Rick and Morty API: https://rickandmortyapi.com/

Documentação: https://rickandmortyapi.com/documentation

## Endpoint utilizado
https://rickandmortyapi.com/api/character/{id}

## O que a página faz
A página permite pesquisar personagens de Rick and Morty pelo número. Ela mostra as principais informações dos personagens.

## Como abrir
1. Baixe ou clone o projeto.
2. Abra o arquivo `index.html` no navegador.
3. Digite o número de um personagem e clique em **Buscar**.

O projeto utiliza HTML, CSS e JavaScript, com `fetch`, `async/await`, `try/catch` e `createElement`.
